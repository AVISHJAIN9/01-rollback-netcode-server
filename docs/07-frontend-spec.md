# 07 - Frontend Specification: Rollback Netcode Server

## 1. Visual Design & Tech Stack [Specified]
- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: TailwindCSS with bespoke dark futuristic HUD theme (`#0B0E14` dark slate, `#00F5FF` cyan accent, `#FF2E93` magenta warning).
- **Motion & Smooth Scrolling**: Lenis smooth scroll engine coupled with GSAP ScrollTrigger.
- **3D & 2D Graphics**: Three.js via `@react-three/fiber` for hero visualization; HTML5 Canvas for the 60 FPS deterministic 2D arena client.

## 2. Page Hierarchy & User Journeys [Specified]

### 2.1 Landing Page (`/`)
- **Navigation Bar**: Links to `/`, `/dashboard`, `/arena`, `/ai-insights`, and "AI Diagnostics" action button.
- **Hero Section**: 3D interactive viewport rendering animated arena wireframes.
- **Feature Grid**: Detailed breakdown of Q16.16 math, Blake3 checksumming, and rollback ring buffers.

### 2.2 Telemetry Dashboard (`/dashboard`)
- **Snapshot Ring Buffer Visualizer**: Circular animated SVG gauge representing 128 buffer slots. Slots transition dynamically between `Confirmed` (Green), `Predicted` (Cyan), and `Rolled-Back` (Amber).
- **Jitter & RTT Real-Time Graph**: Live timeseries charts tracking raw network transit delay vs Kalman Filter smoothed projections.
- **Rollback Rate Monitor**: Displays rolling average resimulation depth (frames rewound per second).

### 2.3 Interactive 2D Arena Playground (`/arena`)
- **Canvas Renderer**: Displays player avatars, physics bounding boxes, projectile trajectories, and authoritative server "ghost" positions.
- **Network Impairment Injector**: Interactive sliders to simulate artificial latency (0 - 300 ms), packet loss (0 - 50%), and jitter (0 - 100 ms).

### 2.4 AI Diagnostics & Explainer Studio (`/ai-insights`)
- **Cheat Detection Panel**: Scatter plot of input velocity vectors with decision boundaries generated by the Isolation Forest model.
- **Desync Diff Explorer**: Side-by-side JSON diff viewer highlighting mismatched state variables with one-click "Explain with AI" LLM diagnosis.
